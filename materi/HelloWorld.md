# React

## Component

Component pada react menggunakan JSX atau TSX (typescript xml).
React components are strictly required to return a single root element. If you try to return multiple sibling elements without a parent wrapper, React will throw an error.

- setiap tag wajib ditutup.
- single tag with close : `<img/>`
- double tag with close : `<div></div>`
- all component must being wrap with fragment (`<></>`) or div (`<div></div>`) or section (`<section></section>`).
